Request lifecycle (one chat turn)

  1. The customer types a message in the browser, and Streamlit re-runs app.py.
  2. The message is added to st.session_state.messages, which already starts with the system prompt.
  3. The whole message list (system prompt and every past turn) goes to the LLM client.
  4. The OpenAI SDK sends an HTTPS request to OpenRouter's OpenAI-compatible endpoint, authenticated with the API key.
  5. OpenRouter routes the request to gpt-4o-mini and returns the completion.
  6. The assistant reply is added to the session history.
  7. The reply is shown in the chat. On failure, an error appears and the unanswered user message is removed.
